Trang Debug JavaScript

Đoạn mã gốc có lỗi

function showGreeting() {
    let hour = new Date().getHours();
    let greeting = document.getelementbyid("23010001_txt_msg");
    if (hour < 12) {
        greeting.innertext = "Chào buổi sáng!";
    } else (hour < 18) {
        greeting.innertext = "Chào buổi chiều!";
    }
}

Đoạn mã đã sửa

function showGreeting() {
    let hour = new Date().getHours();
    let greeting = document.getElementById("23010001_txt_msg");

    if (hour < 12) {
        greeting.innerText = "Chào buổi sáng!";
    } else if (hour < 18) {
        greeting.innerText = "Chào buổi chiều!";
    } else {
        greeting.innerText = "Chào buổi tối!";
    }
}

Giải thích lỗi

  • getelementbyid → Sai cú pháp, phải là getElementById.
  • innertext → Phải viết đúng là innerText.
  • else(hour < 18) → Sai cú pháp, phải dùng else if.
  • Bổ sung trường hợp buổi tối để hoàn thiện chức năng.
