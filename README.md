
# Hệ Thống Quản Lý Chi Tiêu Sinh Viên

## Chức năng
- Trang chủ có Carousel + Jumbotron
- Trang quản lý nhập khoản chi bằng Form Bootstrap
- Hiển thị dữ liệu dạng bảng
- MSSV lẻ chèn đầu bảng, MSSV chẵn chèn cuối bảng
- Cảnh báo khi tổng chi > 1.500.000 VNĐ
- Trang Debug sửa lỗi JavaScript theo đề bài

## Cách chạy
Mở file `index.html` bằng trình duyệt.
